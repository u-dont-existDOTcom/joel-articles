## Sentence audit

### Sentence 1

`In Somatic Experiencing, if meaning is hogging the show, you do not have to sort the beliefs and judgements out first; you can move some attention to sensation.`

This is locally traceable, but functionally it is very close to the immediately preceding accepted sentence that one can direct attention toward individual layers that are `hogging the show`, combined with the already-established concurrent bottom-up/meaning relation.

The phrase `sort the beliefs and judgements out first` is a slightly stronger procedural realization than the literal upstream wording, but it is broadly supported by the accepted `first or concurrently` relation. It is not the main defect.

The main defect is that the sentence spends Stage-1 space operationalizing a distinction the reader has just learned instead of advancing what `stay present and keep choice` means in the SE context.

### Sentence 2

`That sensation might be as plain as tension or heat.`

This is exactly source-grounded, but it adds essentially no new reader value at this location: `tension` and `heat` were just given as examples in the accepted Sensation definition above.

It passed the prior **within-candidate** anti-paraphrase gate because it contributed specificity relative to sentence 1. It fails the **cross-boundary** test because the specificity is already on the page immediately before the heading.

### Sentence 3

`The meaning layer is still there while you do that.`

The strongest defense is that this prevents bottom-up attention from implying that meaning should be discarded. That defense fails on the actual article boundary: the immediately preceding accepted paragraph already states that meaning/narrative work may remain useful concurrently.

A reasonable reader does not need the reassurance again. The sentence is therefore explanatory aftercare and creates a tidy return to the opening concept.

## Method diagnosis

The literal-field + anti-paraphrase map fixed internal paraphrase loops but only compared candidate sentences with one another.

Because the generation field exposed recently established SIBAM material as positive generative material, the writer naturally elaborated what the reader already knew. The retrospective gate then preserved sentence 2 as `new specificity` and sentence 3 as `concurrent meaning`, even though both were already explicit upstream.

The missing object is **reader-state delta across the section boundary**:

- What is already established and should not be re-earned?
- What does the new heading promise that is not yet available?
- Does the candidate actually change the reader's position relative to that promise?

This should be added without restoring a future-obligation list or per-sentence state machine.
