## Correction

Do not assume a heading or subsection has one humanization route.

A natural subsection may contain genuinely different source/genre/thought movements—for example:

- protected owner or practitioner material;
- one model-written placement/interpretation movement;
- technical mechanism/evidence explanation;
- a protected safety warning.

Applying one rewrite method to the whole heading can either:

1. force technical/safety material into narrative prose; or
2. preserve a model-shaped narrative movement merely because neighboring technical structure is legitimately finite.

## New routing unit

Route at the **smallest natural movement with a shared source/genre/thought relation**.

This is not permission to atomize prose into preservation units or sentence cards.

A valid movement normally has:
- one locally live relation or function;
- coherent provenance/source role;
- one genre mode (narrative realization, technical explanation, safety instruction, owner anecdote/source, etc.);
- a real stopping point.

Do not split merely because two claims can be listed separately. Split only when the operation that would improve one movement would be inappropriate for the adjacent movement.

## Specificity control

Before diagnosing a surface feature as model-shaped, check whether the same feature is content-native in tolerated neighboring movements.

Examples from the Stage-2 Shaking Qigong dry run:

- lists are legitimate when enumerating actual mechanisms/use cases or a real sequence;
- contrast is legitimate when separating evidence planes;
- negative language is legitimate in a real safety prohibition;
- finite technical structure is not equivalent to model-created conceptual completion.

Therefore humanization diagnosis should target the **relation the surface is performing**, not the visual form alone.

## Operational consequence

For a mixed-route heading:

1. map movements before rewriting;
2. assign each movement V3 Route 0–5;
3. retrieve a historical correction only for the movement that has a real analogous failure;
4. keep unaffected Route-0/4 material outside the writer packet;
5. preserve cross-movement dependencies and transitions afterward;
6. run preservation/architecture checks across the full natural subsection after any local change.

The movement map is a supervisor diagnostic, not a composition outline for the writer.

## Current validated usability example

`Stage 2: Shaking Qigong / Shaking Medicine` dry-run routing:

- Louka callout -> Route 0/1 preserve absent real defect;
- Stage-2 placement/dose/use paragraph -> Route 2, with Route-3 escalation if fuller owner cognition is needed;
- ordinary mechanism paragraph -> Route 4 technical/evidence;
- qigong explanatory-language paragraph -> Route 4 evidence-plane distinction;
- catharsis/instability warning -> Route 4 safety.

Only the placement/dose/use movement earned trajectory retrieval; the primary analogue was `JBT-002-somatic-stage1-triad-program`.

This is **method-usability evidence only**, produced in the same saturated context. It is not independent evidence that retrieval improves prose.

## Guard against reverse atomization

The correction above must not recreate the original problem in a new form.

Do not produce:
`owner card -> technical card -> evidence card -> safety card`

merely because the supervisor identified source roles.

Those labels determine **which editing operation is permissible**, not how the eventual prose must be paragraphized. Existing natural transitions and thought continuity may cross role boundaries when they genuinely do so.
