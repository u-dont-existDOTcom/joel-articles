## 1. Somatic Experiencing lead — REJECT

Current model-written sentence:

`Titration, pendulation, and orientation are all ways of asking: can you touch something difficult in a small enough dose, notice what happens, and come back?`

### Surface shape

This is a particularly clear nested-enumeration construction:

- technical triad: `titration / pendulation / orientation`;
- procedural triad: `touch / notice / come back`.

The colon creates a polished one-to-one-feeling translation from one three-slot package into another. Even though the second triad is not a literal definition of the first, the rhetoric makes the sentence feel as if three technical terms have been compressed into one neat operational algorithm.

### Semantic problem

## 5. Stronger causal diagnosis: preservation-unit serialization

The recurring generator defect is now clearer.

The model sees several protected semantic units and compresses them into coordinated slots. When it knows the inventory, the compression appears as:

- `A, B, and C` terminology groups;
- `X, Y, and Z` action groups;
- sequences of three short rules;
- one paragraph per inventory class;
- compact problem -> remedy -> implementation chains.

This is **preservation-unit serialization**: the model treats multiple things that must survive as data fields that should be efficiently emitted. That is why the prose can remain list-shaped even after bullet lists are forbidden and even when sentence length varies.

Do not promote `avoid the number three` as the lesson. Two-item and four-item serializations can have the same defect. The diagnostic question is whether the sentence/paragraph exists because several inventory slots need to be emitted, rather than because one live thought naturally requires those details at that moment.

## 6. New blocking audit gate — nested enumeration / program shape

Before accepting model-written Joel prose, reject or reopen when either occurs without a strong content reason:

### Nested enumeration

A sentence contains more than one coordinated enumeration, especially when one list rhetorically translates, explains, or operationalizes another.

Canonical current failure:

`A / B / C are ways of X / Y / Z.`

### Compact program shape

A short run of sentences can be reduced to:

`condition -> problem -> remedy -> implementation`

or

`state -> instruction -> operational example`.

Plain vocabulary and short sentences do not rescue this if every beat occupies a clean procedural slot.
