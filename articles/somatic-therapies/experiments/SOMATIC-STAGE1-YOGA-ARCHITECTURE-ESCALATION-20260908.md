## Architecture B — short authorial nucleus + honest reference island

Structure:

1. a very short prose nucleus carrying only the functional-interoception thought;
2. one clearly non-essay reference island for the practical Yoga guidance;
3. no prose sentence whose job is to transition from each inventory class to the next;
4. no explanatory closing sentence after the reference material.

The reference island could be a compact list/callout or another plainly navigational form. Its final presentation is not fixed by this proposal.

Advantages:

- stops pretending a genuine inventory is continuous thought;
- removes model connective tissue between forms, cues, and warnings;
- keeps the authorial prose at its semantic ceiling;
- preserves all source functions transparently.

Risk:

- Joel has already rejected model-generated `tidy lists`. Therefore any explicit list must be justified as **actual reader navigation**, not as model rhetoric, and should preserve source categories/items rather than inventing a neat taxonomy.

## Architecture C — distribute reference items across neighboring Stage-1 practices
