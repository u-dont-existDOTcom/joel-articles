## Core shift

### Old production unit

`one modality subsection -> make it complete and natural`

This creates a hidden obligation to cover:
- what it is;
- why Joel includes it;
- who/what it is for;
- how long;
- mechanisms;
- evidence plane;
- risks;
- what to do afterward.

Even when each unit is real, that completeness pulse is model-shaped.

### V6 production unit

`one Stage-level live pressure -> follow it serially through whatever practices actually become relevant`

A modality heading is navigation, not a contract to finish a profile before the prose can move on.

The writer is not asked to `cover EFT`, `cover Shaking`, or `complete Shaking`. It sees the literal current Stage-2 prose plus the minimum next owner/source material needed to continue the live thought.

## Serial composition architecture

V6 uses **serial local composition across the full Stage boundary**, not one-shot Stage reconstruction.

### Step 1 — freeze Stage-2 custody outside the writer

Supervisor holds all required semantic/protected units, including:
- current Stage-2 opening function;
- EFT functions;
- protected Louka report/link;
- SE can itself include shaking/discharge;
- Joel's practical reason for trying more deliberate shaking;
- stop/orient/settle safety;
- 10–45 range;
- four use contexts;
- non-qigong mechanism items;
- qigong explanatory items/evidence plane;
- catharsis / instability safety;
- optional post-shaking EFT/massage/restorative-yin settling;
- yin safety;
- routed solar-plexus/abdomen / heart-love / younger-part loop owner material;
- downstream Stage-3 boundary.

This inventory is **never shown to the production writer as a checklist**.

### Step 2 — expose only the live local source

For each serial movement, writer input is limited to:

1. the literal reader-visible prose immediately before the frontier;
2. direct owner source that actually answers the current live question;
3. minimum factual correction/attribution needed to avoid error;
4. any safety fact that must be adjacent **now**.

Do not expose later technical custody merely because it eventually must survive.

### Step 3 — minimum transformation, then stop

When direct owner source exists, use V5 minimum transformation.

Do not request a paragraph count or complete subsection.

Stop when the current thought stops, even if Stage-2 custody remains unresolved.

### Step 4 — choose the next frontier from literal reader state

After each completed movement, cold-read only what a reader now has.

Ask:

`What is the next genuinely live question or consequence created by this literal text?`

The answer may:
- continue the same thought;
- bring in another modality;
- require a technical fact;
- require safety;
- move to Joel's personal consequence;
- stop and leave a custody item for later placement.

This checkpoint is diagnostic. It is **not converted into a full Stage outline**.

### Step 5 — headings are inserted/retained only after movement exists

Existing headings may remain for navigation, links, and scanability, but they must not determine prose architecture.

In particular:
- `EFT / Tapping` may remain without requiring a full EFT profile;
- `Shaking Qigong / Shaking Medicine` may remain without requiring dose + mechanisms + warnings + aftercare before leaving it;
- `After Shaking` is **not presumed to exist**. Joel's settling thought can continue without a fresh heading if that is what the prose does.

Any heading change still requires exact placement/change-control proof.

## Technical-custody insertion pass

The main new protection is that technical custody is inserted **after**, not during, authorial-spine composition.

### Pass A — authorial/reader spine

Serially recover Stage 2 using:
- current Stage-level pressure;
- direct Joel cognition;
- protected anecdotes/personal material;
- minimum adjacency safety.

Freeze that literal spine before exposing the writer to full technical inventory.

### Pass B — technical insertion

Then process each unresolved technical unit individually.

For each unit ask:

1. Does the literal Stage-2 spine create a reader question this unit actually answers here?
2. Can it enter without resetting the prose into `now dose`, `now mechanisms`, `now caveat`?
3. Is prose the right genre, or should this remain an explicitly technical note/list/reference object?
4. Does the item truly need this exact location, or only Stage-2/subsection custody?

If insertion would recreate a modality card:
- do **not** paraphrase harder;
- retain the unit in supervisor custody;
- run a placement audit for a named Stage-2 location or another owner-authorized destination;
- if a real placement choice remains, make that choice explicit rather than burying it in prose.

No unit may be deleted merely because it is difficult to integrate.

## Safety insertion rule

Safety remains special because adjacency is a protected function.

But `adjacent` does not mean `collect all negatives into a final warning paragraph`.

Insert a safety statement at the point where the risky use becomes reader-live.

Examples of legitimate local functions:
- stop/orient/settle when stronger shaking is introduced;
- catharsis/instability warning where intensity/regular discharge is actually discussed;
- yin coercion/hold-length caveat where yin is actually proposed.

Preserve all safety meaning while allowing different distribution.

## Evidence-plane rule

The non-qigong and qigong mechanism inventories remain protected semantic/evidence objects.

V6 does **not** require a balanced `mainstream explanation` paragraph followed by a `qigong explanation` paragraph, or one combined mirrored paragraph.

Their final form is chosen only after the Stage spine exists.

Possible valid treatments, subject to preservation/placement proof:
- brief prose where the reader genuinely asks why shaking might work;
- an explicitly technical note rather than pretending the inventory is part of Joel's live narrative movement;
- separated attribution at the exact point where the qigong concept enters.

Do not use external wording as detector camouflage.
