# Somatic Stage 1 — editorial microworld exploration-map experiment — 2026-09-06

Status: **NON-AUTHORITATIVE METHOD PROBE / OWNER REVIEW PENDING**.

This experiment does not modify article authority, owner-accepted prose, locks, links/media/native objects, or the working merged article. No Pangram call was run.

## Why the prior map failed

The previous visual map removed the Stage-1 preservation inventory from the visible writing route but replaced it with another predetermined sequence of conceptual destinations (`in the middle -> fear -> possibility -> glimpse -> open ending`). The prose therefore still followed an authored route rather than discovering its next move from the local state. The subsequent cold audit also found conspicuous acoustic engineering (`short -> long -> short -> long -> short`).

The failure mechanism is therefore not merely bad wording. It is **planned semantic trajectory plus planned cadence**.

## New hypothesis: editorial microworld rather than thought outline

Treat the local writing problem as an interactive environment.

The environment contains facts, constraints, and a current unresolved pressure. It does **not** contain a planned sequence of discoveries.

### World model

The world model may know:

- exact article location and heading promise;
- current owner/source claims and certainty;
- authorized semantic material for this bounded movement;
- prohibited inventions and provenance boundaries;
- full preservation obligations, kept sealed from the local explorer until reconciliation.

For the first Stage-1 / Somatic Experiencing movement, the active world may expose only source-grounded relations needed to begin:

- activation can outrun choice;
- Stage 1 is about staying present so choice about what comes next remains possible;
- Somatic Experiencing is the early modality example at this location;
- current source permits body/sensation, orientation, pacing, and approach/return relations when naturally reached.

Later Stage-1 obligations are not presented as next destinations.

### Explorer / writer

The explorer receives only:

1. the literal prose written so far;
2. the current local world state;
3. the source-grounded affordances currently available;
4. the blocking boundaries.

It generates **one sentence/action at a time**.

It is not told which concept must come next.

## State transition after every sentence

After each sentence, evaluate the literal consequence:

- What is newly true or newly available to the reader?
- What question or pressure did the sentence actually create or deepen?
- Did the sentence change time, case, premise, causal state, consequence, or available action?
- Did it merely restate the existing state?
- Did it introduce an unexplained metaphor, clinical fact, symptom example, mechanism, timeframe, or certainty change?
- Did it switch conceptual jobs because of an external outline?
- Did it prematurely summarize or close a still-live thought?
- Is there a genuinely local next move, or has this movement stopped?

The resulting state—not an outline—controls the next sentence.

## Reward / blocking model

Positive signal:

- genuine state change;
- locally necessary consequence;
- source-grounded concrete relation;
- sustained unresolved thought where appropriate;
- reader-facing heading progress without exposition for its own sake.

Block or heavily penalize:

- restatement with no state change;
- explanatory aftercare;
- hidden preservation checklist traversal;
- predetermined `problem -> solution -> reassurance` progression;
- invented concreteness/metaphor used merely to create movement;
- aphoristic or summary landing when the thought remains live;
- changing conceptual jobs because another protected function remains;
- deliberate alternation of sentence lengths.

## Acoustic handling

Do **not** pre-map sentence duration.

Acoustic cadence is observed as an emergent trace of the state transitions. After a natural movement exists, cold-audit for suspicious regularity, equalized thought duration, repeated closure, or deliberate short/long alternation. Repair the causal thought movement rather than imposing a different meter.

## Preservation boundary

The full Stage-1 preservation inventory remains authoritative but is hidden from local generation. After a natural movement terminates:

1. run forward/reverse traceability for the bounded movement;
2. reject unexplained substantive deltas;
3. mark every later unsatisfied Stage-1 unit as deferred, not deleted;
4. begin a separate natural movement only when its own local pressure exists.

## Stop condition

Stop when the current state offers no genuinely necessary next move inside the same thought.

Do not manufacture a closing sentence to signal completion.

Do not expose a later preservation unit merely to keep writing.

## Relation to interactive-learning systems

This is an editorial analogy to interactive agent learning, not a claim that the model is retraining its weights. The intended mechanism is repeated local observation -> action -> consequence -> updated state, with compact retained state and source-grounded constraints. It is designed to avoid pre-solving the prose trajectory before prose exists.
