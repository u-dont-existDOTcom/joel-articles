## New blocking rule 1 — `same-function` is not blanket supersession

`NATURAL_OWNER_SAME_FUNCTION` means:

- the recovered island is valid authority for the functions it actually carries;
- it may replace lower-authority wording for those mapped functions;
- it does **not** silently delete other unique propositions, examples, scope conditions, safety functions, timing/use contexts, or rhetorical jobs from the displaced source span.

Before calling a recovered island a replacement, run a residual-function diff:

`displaced source units - units actually carried by recovered island = residual function set`

Every residual must receive a canonical controlled disposition.

## New blocking rule 2 — whole-boundary PASS must reconcile the whole displaced boundary

A candidate presented as a **whole Stage / whole section replacement** may not define preservation scope as only `currently active V7 islands`.

Whole-boundary preservation must cover:

1. every unsuperseded protected/semantic unit in the controlling current source span;

A partial island assembly may have a local PASS. A whole-boundary candidate cannot inherit that local PASS unless the residual units are reconciled too.

## New blocking rule 3 — `banked` is temporary supervisor state, not a final preservation disposition

`BANKED`, `CUSTODY ONLY`, `later`, and `not needed in this movement` are useful during serial composition. They are **not** canonical whole-boundary non-preservation dispositions.

At whole-boundary closeout, each such unit must resolve to one of the preservation gate's allowed states, e.g.:

## New blocking rule 4 — distinguish model packaging from model propositions

V7 already rejects inherited model architecture as order authority. This supplement separates two kinds of model material:

### MODEL_PACKAGING
Examples:
- `Goal / Best use / Mechanism / Warning` slots;
- generic significance staging;
- recap/takeaway shells;
- synthetic transitions;
- balanced caveat wrappers;
- headings whose only function is completing a modality card.

These may be removed/reorganized inside an authorized humanization delta when no unique function is lost.

### MODEL_PROPOSITION_IN_ACCEPTED_WORKING_SOURCE
A model-written sentence can still contain an owner-accepted/current-working proposition or function, such as a concrete use context, scope warning, example, or practical distinction.

Its wording is not protected merely because it is present, but its **substantive function cannot be deleted by relabeling the entire paragraph as model scaffold**.

First establish whether the proposition is:
- source/owner-backed;
- accepted working content;
- later owner-superseded;
- unsupported model invention eligible for explicit removal under the edit whitelist.

Do not infer the last category from model authorship alone.

## New blocking rule 5 — container labels carry semantic scope

A technical/reference heading or label is not neutral formatting when it names the target population, modality, comparator, or object to which the enclosed facts appear to apply.

Before passing a technical surface, audit:

- exact target modality;
- comparator/related-practice roles;
- whether timing/dose/mechanism/use-context bullets are source-specific or shared;
- whether a label widens or narrows those claims.

This rule is semantic target preservation, not detector optimization.

## New blocking rule 6 — do not turn residual debt into a new card architecture

When residual functions are discovered, **do not automatically serialize them as bullets, a `Practical notes` card, a `What to know` box, or a new mini-profile** merely because this makes traceability easy.

Use this order:

1. search for stronger same-function owner/source realization;
2. check whether later owner authority genuinely supersedes the unit;
3. check whether exact equivalent function survives elsewhere at a named destination;
4. if still live, request the smallest owner content-selection/cognition needed;
5. generate or reformat only after the content set is actually authorized.

The preservation ledger remains verification input, not a composition outline.

## New blocking rule 7 — heading repairs should minimize semantic invention

A new heading may be necessary to prevent false structural scope. That does not authorize a miniature thesis.

When no owner heading exists:

- use the minimum navigational label necessary;
- prefer distinctive nouns already present in the island;
- do not add mechanism, evaluation, causal direction, or significance;
- verify that the heading does not create pressure for a complete subsection that the source thought does not support.

For the current solar/heart island, `Solar Plexus / Heart-Chakra Love` is preferred over the more synthesized `Body Loosening and Heart-Chakra Love` pending owner-final wording.
