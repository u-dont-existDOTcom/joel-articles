## 4. Generation rule

Write naturally from the section contract and open reader question.

Do not ask after each sentence:

- what new concept did this add?
- what technique comes next?
- which preservation item remains?
- how do I make this sentence different from the last?

Do not deliberately repeat an upstream concept merely to create a smooth bridge.

A real bridge is allowed when the new section cannot be understood without it, but bridge necessity is tested retrospectively rather than assumed.

## 5. Retrospective gates after the natural draft

Run these only after a natural movement exists.

### Gate A — within-candidate earned presence

Reduce each sentence to its smallest semantic/pragmatic contribution.

If adjacent sentences collapse to the same contribution, delete/merge unless removing one causes a real loss.

This preserves the prior anti-paraphrase correction.

### Gate B — cross-boundary subtraction

For each surviving contribution, ask:

**What does the reader gain here that was not already explicitly available immediately above Stage 1?**

A sentence fails when its only contribution is:

- a SIBAM definition already supplied;
- an example already supplied (`tension`, `heat`, etc.);
- the already-established fact that attention can move among layers;
- the already-established fact that meaning can remain useful concurrently;
- reassurance against an implication the upstream prose already prevented.

Do not demand novelty for novelty's sake. A repeated premise may survive when it is genuinely necessary to establish a new causal or practical relation under the new heading.

### Gate C — counterfactual placement test

Ask:

**Could this paragraph be moved back into the preceding SIBAM / trauma-memory discussion with little or no change?**

If yes, presume Stage-1 heading drift until a distinct section-specific function is demonstrated.

This is the main discriminating test exposed by the rejected 2026-09-06 candidate.

### Gate D — heading-removal test

Temporarily hide:

- `Stage 1: Stay Present and Keep Choice`
- `Somatic Experiencing`

Then read the paragraph alone.

Ask whether the prose itself materially connects the method to the Stage-1 problem, or whether the headings are doing almost all the work while the paragraph remains generic somatic exposition.

Failure here does not require jargon or technique names. It means the method/problem relation has not become reader-visible in the prose.

### Gate E — strongest-objection test

For any sentence that looks like caveat/reassurance/aftercare, formulate its strongest defense.

Then check whether the reader actually needs that defense given the literal upstream text.

Example from the rejected candidate:

`The meaning layer is still there while you do that.`

Strongest defense: prevents bottom-up attention from implying that meaning is discarded.

Boundary check: upstream already states that meaning/narrative work may remain useful concurrently.

Result: defense fails; delete the aftercare.

### Gate F — source/fidelity veto

Only after the reader-movement gates, verify:

- actor/agency;
- chronology;
- certainty;
- source provenance;
- no invented symptoms, mechanisms, outcomes, memories, timeframes, or factual micro-details;
- no unexplained substantive delta.

A paragraph can be fidelity-clean and still fail Gates B–D.

### Gate G — acoustic / thought-shape audit

After semantic compression, inspect:

- equal-weight sentence staircase;
- matched antithesis;
- `rule -> example -> reassurance` cards;
- neat semantic return/sandwich closure;
- mini-essay landing;
- artificial fragments or cadence variation added only to sound human.

Repair thought relation, not meter.

## 7. Stopping rule

Stop when the current Stage-1 reader question has genuinely advanced to a natural pause.

Do not continue because:

- the paragraph is short;
- a named SE technique has not appeared;
- later Stage-1 preservation items remain;
- the section `needs` a takeaway;
- a caveat could make the prose more defensible.

Do not stop merely because one sentence answered part of the question if a real reader pressure remains inside the same movement.
