There is a real benefit to preparing a session before you start and once you've gathered your subject's attention you can deepen if necessary but you're free to start wording up if the context of the session requires it. You can use a number of ways to organise your subject's attention, counting is but one and if you're going to use it then say so. You can use conversation, stories, movement, repeated sounds, or simply curiosity etc... But if you're going to use them say so. Elegence is always useful, but not at the expense of doing something that you shouldn't be doing.

Also, with a simple enough target, why not try it first and if it works then deepen.
