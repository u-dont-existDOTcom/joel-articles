The weekly deeper practice

Practise this once or twice a week and spend a bit more time with it if that would be useful but don’t make the practice any stronger. Whenever it is useful just access Higher Self, or if that is not possible go to a neutral witnessing place and let it unfold, using any adult function that is necessary to recognise any bypassing that may be going on and always allowing for a full exit and any necessary normal action.

Wherever possible take any normal action immediately afterwards to impress on the subconscious that something has changed, otherwise it may think that because the dishes have not been done, despite all the internal meetings to do the dishes, that there is no point in doing them.
