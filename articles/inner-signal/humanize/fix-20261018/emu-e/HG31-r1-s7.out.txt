Be careful with how language link events. Words like “as, while, because, when, after, before, which means” etc are all words that can be used to link events.

In general, the problem with the first example is that it’s likely to be inaccurate. It’s unlikely that simply breathing will get rid of the trauma. So while the intention is good, the phrasing is a bit strong. The second example is better because it’s more accurate. As long as the breathing is going on, it’s more likely that the adult version of yourself will be able to get involved in the process and try to help the wounded part of yourself.
