One rule of thumb for deciding whether to keep going with something or not in a situation like this is if it’s making you more loving, more grounded, more relational, more honest, more functional, etc, then it’s probably ok to keep doing it, but gently. If it’s making you more Paranoid, more sleepless, more grandiose, more isolated, more scared, more unreal, etc, then don’t go deeper, go and get help.
