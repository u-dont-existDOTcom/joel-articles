The tool: Uridine monophosphate (UMP). There isn’t a study that shows “UMP cures DAWS,” so the evidence we have is more basic than that. Uridine, choline, and DHA are circulating precursors the brain uses for phosphatide / synaptic membrane synthesis, and Wurtman’s group has shown that [DHA + uridine + choline can increase synaptic membrane components and synaptic proteins](https://pmc.ncbi.nlm.nih.gov/articles/PMC4011061/), that [DHA-induced dendritic spine formation is enhanced by UMP](https://pmc.ncbi.nlm.nih.gov/articles/PMC2140951/) in animals, and that [dietary UMP increased potassium-evoked dopamine release and neurite outgrowth in aged rats](https://pubmed.ncbi.nlm.nih.gov/16055952/). So the mechanism is plausible, but using it for DAWS is still a cautious human extrapolation plus anecdote.
