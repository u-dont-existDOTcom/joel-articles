If you've done a lot of therapy and you're still reacting the same way, it might not be the therapy's fault. That's because standard therapy tries to rewrite the "code" (your thoughts and behaviors), and if the "motherboard" (the brain's physical structure and chemistry) is overheating or damaged, the new code won't run very well. So the science behind this protocol looks at four specific neuro-biological problems that must be addressed before psychological tools can really work.
