## Places: all, or one or more?

| Version | A reader believes |
|---|---|
| Published P26 | Says one or more, if any; never all five. No effect asserted ("whether"). All five areas named together, unhedged ("and"), as where the weeks give the answer; "anything" means a change in any one or more counts. Whether the dash list hangs on "reveal" or on "changed", "and" only sets the field. |
| R-P26 | An effect, if any, will show up in one or more places, each offered as a possibility ("maybe … maybe … or"); "and" inside each "maybe" makes relationships+daily behavior and sleep+decisions pairs that show up together. Not all five. |
| R-P26-alt | An effect, if any, will show up in one or more: relationships or daily behavior stated outright, sleep or decisions "maybe", frustration tolerance as another option. Not all five; the first pair reads surer. |
| Net | Both keep the published one-or-more. Both lose the five as one definite field and add pairs; alt also ranks them. |
