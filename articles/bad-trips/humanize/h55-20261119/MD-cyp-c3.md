2. **If the person is fully alert and able to swallow, I would give cyproheptadine early**, since it blocks serotonin receptors. So far, the evidence for it has only been [case reports](https://pubmed.ncbi.nlm.nih.gov/9696181/), and [a recent review](https://pubmed.ncbi.nlm.nih.gov/39791184/) found them too weak to show that it works. I wouldn't wait to see whether it does before doing the other steps.
