## Failure-locus classification

### 1. PLAN GENERATION FAILURE — YES

The plan selected an entry strategy and several exclusions, but it did not freeze a **governing movement for the complete subsection**. It answered `how should this begin?` more clearly than `what continuous thought should carry the reader to the next heading?`

That omission mattered. Once the concrete opening scene was chosen, the remaining preservation units were still available to fall back into source/ledger order. The plan never specified how one-event uncertainty, Gibson, repeated behavior, motive uncertainty, guilt, revisability, behavior-versus-promises, protection, and action-without-understanding were to coexist inside one live movement.

The plan also treated `no checklist/listicle` as an abstract prohibition rather than a structural admission test. It therefore removed the `Witness / Protector / Guide` labels without detecting that the same three-part taxonomy could reappear isomorphically as `notice / see / decide`.

The plan removed the repeated old opening sentence but failed to compare the **heading itself** against the immediately preceding owner-final paragraph. `Don't Assume It's All You` still re-announced the thesis that the upstream paragraph had just completed.

Finally, the three-prediction stage did not actually compare three materially different architectures. Joel had already identified A and C as similar. Combining A and C was therefore a refinement within the same family, not a discriminating architecture choice.

**Plan repair:** future planning must freeze (a) one governing movement across the full natural boundary, (b) the social/pragmatic act, (c) the true stopping point and downstream handoff, and (d) a hidden-outline test that rejects a source taxonomy merely renamed into parallel verbs. Predictions must be materially different in architecture, not merely different openings or tones.

### 2. IMPLEMENTATION / GENERATION FAILURE — YES

Even relative to the imperfect plan, the generated R12 prose violated the plan's own anti-listicle intent.

The generator recreated the model default several times:

- paragraph 1: concrete scene -> responsible caveat -> repeated-pattern threshold;
- paragraph 2: two-question soft checklist followed by serial qualifications and decision rules;
- paragraph 3: mirrored `Maybe X / Maybe Y / both can be true` therapy symmetry;
- paragraph 4: the removed role taxonomy returned as `notice you're upset / see what's happening between you / decide what to do next`.

It also created a neat generic ending rather than using the live interaction to hand naturally into the following `Write It. Don't Send It Yet.` practice.

So R12 was not merely the faithful implementation of a bad plan. The generation step also failed to execute explicit plan constraints.

**Generation repair:** do not generate from the preservation-unit ledger as an implicit outline. Generate from the frozen governing movement and the retrieved literal owner-teaching examples. Use the preservation ledger afterward as a fidelity validator. Before delivery, compare the prose's hidden outline against the source taxonomy and plan; if the same categories survive as renamed parallel clauses, generation fails admission.

### 3. ADMISSION / COLD-AUDIT FAILURE — YES

The initial R12 audit explicitly identified paragraph 2 as a credible mini-diagnostic-checklist risk and nevertheless returned `PASS FOR OWNER REVIEW`.

That was incompatible with the cold-audit rule that a substantive unresolved defect prevents a clean pass. More importantly, the audit localized the defect to paragraph 2 and missed four visible larger-scale problems:

- heading repetition against the owner-final upstream paragraph;
- paragraph 3's matched therapy symmetry;
- paragraph 4's hidden role triad;
- the whole-boundary voice/mode seam from playful, opinionated owner prose into neutral comprehensive counselor prose.

The causal mechanism was **anchoring on preservation success and generation rationale**. Because R12 had zero unexplained semantic deltas and the source genuinely required many qualifications, the audit treated semantic necessity as partial evidence that their sentence-sized packaging was acceptable. That is exactly what the cold-audit gate is supposed to prevent.

**Admission repair:** a known credible model-shape defect is a FAIL, not `pass for owner review`. Audit the complete natural boundary including upstream and downstream seams. Separate `this function must survive` from `this realization must survive`. Explicitly compare the candidate against the frozen plan and record whether each planned architectural property was actually implemented.

## Strategy switch

The next generation method must be structurally different.

Recommended primary architecture: **single-scene chronological realization**.

One concrete interaction should remain the governing movement from beginning to end. Lindsay Gibson enters briefly because repeated behavior matters more than endlessly solving motives; she should not open a diagnostic framework paragraph. The one-conversation/time/other-boundary caveat should appear only where the live scene makes it necessary. Guilt should complicate the same interaction rather than becoming a matched two-sides lesson. The pressure to be understood should lead to a realistic action threshold and directly into the following writing practice.

The preservation ledger remains mandatory, but its role changes: **validator after generation, not prose outline before generation**.

Before choosing this route, the planning stage should compare it against at least two materially different architectures, for example:

- an authorial-argument continuation from Joel's explicit disagreement with the `all problems are self-created` frame, with Gibson as support rather than framework;
- a dialogue/decision-pressure route in which guilt and the need to be understood arise chronologically inside the exchange.

The point of those alternatives is to test architecture, not create three cosmetic versions of the same counselor passage.
