## Sentence operations after the failed map-only realization

1. Delete the stock introductory frame. Start with the live objection: the hurt was real.
2. Keep that validation in its own uneven beat rather than balancing it with checking in one sentence.
3. Replace the abstract processing/checking binary with the concrete recurrence already in the source: going back a hundred times.
4. Let the actual checking question surface directly.
5. Do not force an answer: allow `maybe new / maybe not`.
6. Clarify that continuing hurt does not settle whether new work is happening.
7. Return to the inherited `hook` function only at the end, after the thought earns it.
