# Episode 008 — Write It. Don't Send It Yet — paragraph-first convergence strategy

Date: 2026-09-19
Status: **ACTIVE / OWNER PARAGRAPH GATE / NO MIXED-BOUNDARY MASKING**

## Owner rule

Each testable paragraph must independently read/test Human. A full-section pass cannot rescue an AI paragraph.

## Architecture

Use exactly three publication paragraphs:

1. **Model P1** — private draft + later edit + valid protest/apology/request/boundary + shorter/no response + keepable later-response promise.
2. **Owner P2** — Joel's exact 113-word Human/medium paragraph.
3. **Model P3** — return to writer + protection/reassurance/help + angry is not automatically childish + outward edit vs inward care.

P1 and P3 are tested independently before any integrated section measurement.

No Human anchor is included in those paragraph tests.

If either paragraph is AI, repair that paragraph only.

Only after P1 and P3 independently pass Human will the complete three-paragraph subsection be assembled and tested as secondary integrated evidence.
