If using the recording, you may want to read through the script first. As always, you are in complete control. It doesn't matter if some part of you doesn't want to let you stop, because even that part isn't really in charge.

It may be helpful to rehearse this induction and return at least once before using it for any subject matter, so that you're familiar with the entry and return. After that, it won't be necessary to supervise all of it. This helps make the response more effortless. As always, if you say "no," it's "no."
