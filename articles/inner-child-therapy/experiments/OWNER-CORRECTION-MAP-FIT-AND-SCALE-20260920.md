## Scale discipline

A symbolic map constrains **relations**, not word count.

Before adding a sentence, ask whether the source has an unsatisfied meaning/function that requires the extra surface area.

Do not:
- expand a short paragraph merely to make a map visible;
- expand it merely to cross a detector's short-text threshold;
- add questions/examples/aftercare because a donor paragraph happens to contain them;
- treat a longer "more human" realization as inherently better.

If the source already expresses the full thought compactly, the correct operation may be KEEP or a very small local rewrite.

## Next methodological consequence

Natural maps remain useful as a **route-selection constraint**, but only after:
1. target job is identified correctly;
2. source meaning level is frozen;
3. target scale is frozen unless new meaning requires expansion.

Then use local sentence/span engineering inside that scale. A map that requires inventing more paragraph than the source has is the wrong map or the wrong execution.
