## Why this was more than "Pangram feedback"

The stable Human middle did three jobs:

1. **Control context**
   - each detector run shared the same central 110-ish-word region;
   - only the failing flanks changed.

2. **Earned edit scope**
   - the model was not allowed to rewrite the whole subsection;
   - known-good context could not be destroyed by each attempt.

3. **Useful gradient**
   - red-region mutations could be compared against a stable boundary;
   - F -> G showed measurable improvement, so the controller had direction;
   - G -> H completed the convergence.

This is better described as:

**anchored red-region mutation under constant green context.**
