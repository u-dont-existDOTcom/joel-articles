None of this makes the memory fiction, and it doesn't prove you remember it right. It doesn't let anybody off the hook, either. The trial's over, but if repair is owed, it's still owed, whoever did the harm. And keep an ear on the narrator. If they start sounding like "And so that's the way it happened, you idiot," stop.
