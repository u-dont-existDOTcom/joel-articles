## Revised diagnosis

The dominant defect is not primarily list order or section order. It is **predictable compression**:

- one sentence often carries several semantic jobs efficiently;
- paragraphs resolve a question almost as soon as they raise it;
- qualifications arrive exactly where a complete guide would place them;
- multiple examples are compressed into coverage rather than allowed to have unequal weight;
- the prose repeatedly turns lived uncertainty into a concise rule, test, or decision criterion;
- even when wording is conversational, the thought-duration remains short and regular.

The next repair should therefore preserve idea order while changing thought-duration and rhetorical pressure.

## Three repair hypotheses

### A. Decompress the thought without adding new content

Assumption: the main AI signal comes from semantic density and fast closure. Preserve the same order, but let one live question stay open longer. Split multi-function sentences only where a speaker would actually dwell, repeat a word/idea when it carries pressure, and allow some implications to remain implicit because the next paragraph already continues them.

Example target: inner-monologue section. Instead of moving efficiently from deliberate sentence -> other media -> body -> caring action -> reassurance, spend more time on the actual reader worry: `I don't hear a child voice, so am I doing this wrong?` Resolve that worry first, then let the alternatives appear unevenly as needed.

Risk: mechanical expansion can become verbose model prose. Expansion must come from lingering on the reader's live problem, not from adding explanation.

### B. Turn exposition into an actual conversation with the reader

Assumption: the content feels model-shaped because it is delivered as proposition/instruction rather than as a social act. Keep the same idea order but let the prose respond to likely reader reactions in real time: `What if I don't hear anything?`, `Okay, but what if the other person really did something?`, `How do I know if I'm processing or just checking again?`

This is not permission to sprinkle rhetorical questions as a detector charm. The question must be the actual live objection the next existing idea already answers.

Risk: too many explicit questions can create another predictable Q&A architecture. Use only where the reader's uncertainty is already structurally present.

### C. Let concrete action carry the explanation

Assumption: abstract guidance compresses too neatly because the model states the rule first and examples second. Preserve idea order but let source-supported concrete actions do more of the explanatory work. For example, in the hook section, `half the text is already written` and `your hand is going for the drink` can carry the sense of late recognition before the prose names or explains it. In the unsent-draft exercise, the act of rereading and crossing out unfair/confusing material can carry the editing principle without separately summarizing the principle.

No fabricated biography or scenery. Use only actions already present in the source/preservation ledger.

Risk: not every section has a concrete action rich enough to carry the thought; forcing scenes would be fake texture.

## Current preference before owner adjudication

The most plausible repair is a hybrid weighted toward A, with B used only where a real reader objection exists and C used where the source already supplies concrete action. Do not change the order of ideas merely to create variety.
