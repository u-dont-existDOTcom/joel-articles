# Contributing

This is an owner-directed, high-risk public content repository. Unsolicited article prose, biographical assertions, private source material, and publication actions are out of scope.

Before proposing a governance change:

1. open or reference an owner-scoped issue;
2. use a focused branch and pull request;
3. name the exact article boundary, or state that no article content changes;
4. preserve owner locks, claims, rhetorical functions, source uncertainty, and rejected material;
5. run every command in `.github/codex-repository.json` plus `git diff --check`;
6. record residual uncertainty and the next safe recovery action.

Article content may be imported only as a complete, owner-authorized authority family described in `docs/CONTENT-AUTHORITY-AND-IMPORT.md`. Never reconstruct a missing master from notes or silently publish a locally supplied packet.

No license or copyright posture has been selected. Contribution or public visibility does not grant reuse rights; the owner decision remains open in GitHub issue #3.
