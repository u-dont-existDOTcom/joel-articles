# Romance Custom GPT package

This package is designed for a public/shared Custom GPT that lets readers ask questions about Joel Rosenblum’s Romance guide.

## Fast setup

1. Create or edit a Custom GPT.
2. Copy `GPT-INSTRUCTIONS.md` into **Instructions**.
3. Use the name/description/starters in `GPT-CONFIG.md`.
4. Upload the three files inside `knowledge/` as **Knowledge**.
5. Turn Web search ON if you want optional research/verification beyond the guide.
6. Run the prompts in `TEST-PROMPTS.md` in Preview.
7. Share the GPT link.

The raw Substack editor HTML is intentionally **not** a Knowledge file. The clean Markdown source is much better for retrieval, while the media/link map restores native-object locations that prose-only Markdown cannot carry.

The package represents the accepted R7 guide source dated 2026-08-27.
