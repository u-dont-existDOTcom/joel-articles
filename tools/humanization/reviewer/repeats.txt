WHAT COUNTS

A repeat is the same point made twice: the same claim, instruction, caution, reassurance, example or permission, in the same situation or close enough that a reader would feel told the same thing again. It can be far apart (different sections) or adjacent. Shared words alone don't count, and neither does a theme the article keeps developing, if each passage adds a distinct step. A deliberate callback that a reader would recognize as one is not a repeat, but list it separately if it relies on something sections back.

Also list any two passages that contradict each other or pull in opposite directions without saying why.

2. Contradictions, the same way.
