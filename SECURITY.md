# Security policy

This public repository may eventually contain publication automation, source routing, and article evidence. Never put credentials, unpublished private drafts, private correspondence, detector/API secrets, or sensitive source material in a public issue, pull request, workflow log, artifact, or state file.

## Current reporting status

GitHub private vulnerability reporting was verified **disabled** on 2026-08-14, and no alternative owner-approved private reporting address is published here. Therefore, do not disclose a sensitive vulnerability publicly. The owner must enable a private channel before accepting sensitive reports.

Non-sensitive governance defects and the missing private-reporting control are tracked in [GitHub issue #3](https://github.com/u-dont-existDOTcom/joel-articles/issues/3). That public issue is not a channel for exploit details, credentials, private drafts, or personal information.
