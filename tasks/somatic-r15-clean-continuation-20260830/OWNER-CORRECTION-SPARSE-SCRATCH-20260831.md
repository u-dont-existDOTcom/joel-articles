# Owner correction — sparse scratch, not exhaustive scratch

Updated: 2026-08-31
Status: CURRENT PROCESS CORRECTION

Joel corrected the exploratory writing experiment: even the supposed `scratch mode` was still model-shaped because it exhaustively generated every possible thought around a very small section.

The failure is not merely verbosity. It is **coverage pressure applied to private cognition**. The model turned scratch into a complete transcript, as if a real writer would enumerate all possible associations before drafting.

Corrective rule:

- Scratch is sparse, opportunistic, and discontinuous.
- A real writing session may produce only one to five fragments, one question, one remembered phrase, or nothing useful at all before stopping.
- Do not enumerate all possible thoughts, implications, objections, associations, or semantic obligations.
- Do not fill silence. `I don't know` is a legitimate terminal state for the moment.
- Do not produce scratch for an audience; no explanation of why a fragment matters is required.
- Do not create a complete private chain merely because the model can.
- If a fragment triggers a genuinely interesting memory, question, or external lookup, follow that one thread only until attention moves or stops.
- Future semantic reconciliation happens after exploratory writing; it must not retroactively justify exhaustive scratch generation.

A useful diagnostic: if the scratch for a 150–250 word passage is itself hundreds of words long and systematically touches nearly every source obligation, the scratch process has almost certainly reverted to model coverage behavior.
