# Cognition / Prose Separation Protocol — 2026-08-31

Status: ACTIVE OWNER-DIRECTED EXPERIMENT for the Somatic Introduction. Not article authority, detector evidence, or permission to invent facts.

## Owner correction

Persona prompting and `NEAT = DANGER` failed when they remained inside the same prose generator that already knew the full semantic map and anti-pattern history. The next experiment separates thought generation from prose realization.

## Protocol

1. Generate privately only a tiny pool of fragmentary thought mutations. No sentences intended for publication, no complete semantic coverage, no paragraph plan.
2. Do not expose the whole source map, rejected-strategy history, or anti-pattern ledger to the realization step.
3. Select one mutation only because it creates genuine curiosity or a non-obvious relation, not because it covers an obligation or repairs the last criticism.
4. Realize only that mutation in prose. The realization pass does not receive the other mutations as future obligations.
5. Apply `NEAT = DANGER` before accepting each sentence: if the candidate is attractive mainly because it closes, balances, summarizes, packages, or completes, reject it before output.
6. Stop when the selected thought is exhausted. Do not bridge to the next semantic unit merely to reach length.
7. A later pass may select a different mutation and begin a new paragraph if it naturally belongs nearby. Coherence is checked afterward; it is not preplanned.
8. Semantic reconciliation remains deferred during this exploratory pass under Joel's direct instruction. Production use still requires full preservation/provenance/architecture/cold-audit gates.

## Important limitation

This is procedural isolation within one model context, not true model/context independence. It may reduce attractor contamination but does not prove that the realization step is actually blind to prior context. If the same architecture keeps reappearing, the experiment is falsified in this environment and should not be described as successful isolation.
