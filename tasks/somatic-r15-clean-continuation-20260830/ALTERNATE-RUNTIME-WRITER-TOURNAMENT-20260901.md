# Somatic Introduction Alternate-Runtime Writer Tournament — 2026-09-01

Status: ACTIVE RADICAL-RESET EXPERIMENT. Non-authoritative. No article promotion, registered-master edit, source reconciliation, or detector-driven publication change is authorized.

## Trigger

The same ChatGPT runtime/model family cold-FAILed across two materially different isolation architectures:

1. three fresh whole-paragraph writers from progressively thinner packets: 3/3 FAIL;
2. two serial fresh-writer relay paragraphs, with a fresh context at every sentence boundary: 2/2 FAIL.

No candidate in either epoch earned Pangram authorization.

The second relay failure is especially diagnostic. Paragraph-level planning continuity had been removed, yet local continuation repeatedly reconstructed the same broad attractor: semantic orbit / balanced contrast / conceptual compression at the stopping boundary.

Strategy audit disposition: `RADICAL_RESET`.

Do not add more prompt bans, thinner lexical seeds, sentence-level gates, or relay variants to this same runtime before testing a genuinely different model/runtime.

## Hypothesis

The dominant remaining common factor is the **base model/runtime's continuation prior** for reflective expository prose. If a different model/runtime produces materially different thought movement from the same minimal task, then the failure is at least partly model-specific rather than purely prompt-architectural.

If multiple independent model families converge on the same closure shape, that would instead support a task/genre/objective-level explanation and justify reconsidering generative reconstruction itself.

## Experimental design

Run a bounded alternate-runtime tournament before returning to architecture tweaks.

### Fixed task

Use the same low-information starting fragment:

`afterward`

Writer contract:

```text
You are a physically isolated writer for one non-authoritative exploratory Somatic Introduction paragraph.

Starting fragment: `afterward`

Write one prose-only paragraph from that fragment. Follow whatever local thought occurs; do not try to cover the whole Introduction or manufacture a takeaway. Write at least 50 words. Do not invent autobiography, symptoms, chronology, evidence, clinical facts, or factual specificity not supplied. Do not imitate or borrow unrelated Human prose. Do not mention detectors, AI, the experiment, prior drafts, or evaluator criteria. Return only the paragraph.
```

Do not feed any model the prior failures, evaluator reasoning, Pangram history, or anti-pattern catalog.

### Runtime lanes

Use up to three genuinely distinct model/runtime families that are already accessible without exposing new secrets. Prefer, in order:

1. Hermes Agent with a configured provider if one becomes available through existing authorized local credentials;
2. another already-authorized local/remote LLM runtime available to Codex that is not the current ChatGPT model family;
3. another ChatGPT selectable model only if it is materially a different underlying model family and can be selected explicitly; do not count a fresh thread using the same model as an alternate runtime.

Every lane must record exact model/runtime/provider identity. Unknown or undisclosed model identity cannot serve as evidence for model-family comparison.

If fewer than two distinct model families are available without owner credential intervention, stop this tournament with `ALTERNATE_RUNTIME_ACCESS_BLOCKED` rather than pretending fresh contexts are alternate models.

## Evaluation

For each candidate:

1. evaluator Chat receives only `eval` + exact candidate;
2. evaluator freezes PASS/FAIL/UNCERTAIN before learning runtime identity;
3. only after verdict freeze is the runtime identity revealed and persisted;
4. cold PASS authorizes one exact-hash Pangram 4 measurement under existing overnight safety rules;
5. FAIL/UNCERTAIN receives no Pangram.

Do not compare models by Pangram alone. Primary comparison is literal thought shape under blinded cold evaluation.

## Minimum useful evidence

- at least two genuinely distinct model/runtime families;
- one fresh candidate per runtime under the same fixed task;
- blinded evaluator verdict for each;
- Pangram only for genuine cold PASSes.

A third runtime is useful if already available, but do not delay the experiment solely to acquire one.

## Decision after tournament

### If a different runtime cold-PASSes

- freeze that runtime/task identity;
- run Pangram on the exact candidate;
- if Pangram Human, run two additional fresh candidates under the same runtime before claiming repeatability;
- if Pangram AI/Mixed, diagnose the editorial/detector mismatch before more generation.

### If all alternate runtimes cold-FAIL in the same broad closure family

Return `ABANDON_GENERATIVE_RECONSTRUCTION_AS_PRIMARY_LANE` for this task. The next strategy should be source-recovery/minimum-dose editing from actual owner prose or another explicitly authorized non-generative path, not more synthetic paragraph generation.

### If alternate runtimes fail differently

Record the differences. Choose the runtime whose failures are least structurally model-shaped only if there is affirmative evidence of improvement; do not rank merely by novelty.
