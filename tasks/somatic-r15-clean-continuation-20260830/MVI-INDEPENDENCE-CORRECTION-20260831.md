# MVI independence correction — Somatic Introduction

Updated: 2026-08-31
Status: **CURRENT PROCESS CORRECTION**

## What failed

The first `Mixture of Village Idiots` run was described as though the village had independently cleared the candidate. That description was too strong.

In reality, the same Chat reasoning context serially role-played the narrow idiot checks and then acted as the smart aggregator. The idiot verdicts were therefore not independently instantiated or sealed. The same global model state could reinterpret a narrow criterion in light of the whole passage, rationalize a defect, and later reverse itself.

The concrete miss was the regulation/EMDR topology. The later literal reread correctly found the structure:

`insufficient choice/stability -> regulation`

`choice/stability already present -> EMDR or another trauma-focused method`

That should have produced blocking `FLAG`s from at least V2 (Flowchart Moron) and V9 (Anti-Pull Matcher). Because the same model performed both generation, village simulation, and aggregation, those checks were incorrectly marked clear.

## Correct interpretation

The smart persona did **not** overrule a set of valid independent MVI verdicts. There were no independently sealed verdicts. The MVI execution itself was correlated/self-certified.

Therefore:

- the candidate's prior `MVI clear` status is invalid;
- the later rejection is not a smart-persona override; it is evidence that the simulated village missed a blocking defect;
- a same-context checklist cannot be called a real MVI ensemble merely because it uses multiple named roles.

## Real MVI execution requirement

A future MVI run may be called `independent MVI` only when each narrow idiot is executed in an isolated context/agent that receives only:

1. the literal frozen candidate;
2. its one narrow criterion;
3. the allowed output `FLAG / CLEAR / ABSTAIN` plus exact span/reason;
4. no other idiot verdicts;
5. no drafting history, preservation rationale, detector history, candidate defenses, or global quality task.

Each verdict must be stored immutably before aggregation.

The aggregator:

- may group correlated flags;
- may not convert a blocking `FLAG` to `CLEAR` by balancing it against strengths or other judges;
- may reject a flag only by showing that the narrow judge made a literal factual error about the candidate;
- may add new blocking defects;
- may never erase a surviving blocking defect;
- cannot claim independence if it is the same saturated context that produced or serially simulated the judge outputs.

If independent execution is not technically available, label the procedure `same-context MVI simulation` and treat it only as another adversarial checklist, not as independent verification.

## Promotion rule amendment

For Somatic Introduction owner-facing promotion:

- a real independent MVI clear is stronger evidence than a same-context cold pass;
- a same-context MVI simulation cannot satisfy the independent-verifier role;
- any surviving blocking idiot flag rejects the candidate;
- a subsequent smart/global reader can only add a blocker, not override a surviving narrow blocker;
- if the global reader finds a defect after an apparent MVI clear, inspect which idiot should have caught it and treat the miss as a checker-design/execution failure before using the village again.
