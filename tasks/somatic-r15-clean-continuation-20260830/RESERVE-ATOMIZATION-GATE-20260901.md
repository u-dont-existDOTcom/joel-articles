## Representation rule

1. **One unresolved edge per reserve item.** A reserve item may hold one actor/action edge, temporal edge, verb/object tension, wording snag, consequence fragment, or partial relation whose meaning is not yet complete.
2. **Decomposition test.** Before storing or exposing a reserve item, ask whether it contains two or more independently answerable dimensions. If yes, it is bundled and must be split before any item can be exposed.
3. **No umbrella-object payloads.** A reserve item cannot be a latent category whose ordinary realization invites several criteria, components, signs, stages, reasons, or examples. The problem is representation cardinality, not any particular category word.
4. **Expose one atom only.** When contrastive scheduling fires, expose one atomized pressure to the writer. Keep sibling atoms dormant and invisible.
5. **No sibling completion pressure.** Once one atom lands in prose, the scheduler does not automatically expose its siblings merely because they belong to the same decomposed bundle.
6. **List onset is diagnostic.** If a continuation begins naturally expanding one newly introduced category into coordinated slots, the scheduler checks whether the active pressure was insufficiently atomized. If so, mask the umbrella object and return to a single unresolved edge; do not line-edit the list after the fact.
7. **Atomization is not random fragmentation.** The exposed edge still must arise from literal pressure or a genuinely live reserve item and remain coherent with the buffer.
8. **No source-card recovery through splitting.** Decomposition cannot be used to turn one source obligation into several scheduled sub-obligations. Source coverage remains occluded during discovery.
