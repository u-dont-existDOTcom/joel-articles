Status: **DIAGNOSTIC VIEW ONLY.** This file does not authorize changes to the Romance article.

`results/reduced-reader-gap-register.json`

It contains three deliberately separated evidence classes:

1. **R-series — article-internal review questions:** independently generated `candidate` or `unclear` questions, including the robust workability/ending cluster and the new sexual-fit trajectory candidate.
2. **A-series — answered controls:** important distributed questions that the independent reader judged answered, showing that a live question is not automatically a gap.
3. **E-series — external-only opportunities:** children-after-parenthood, money/labor/household alignment, and ordinary-conflict repair. These have research/framework/actual-reader support but were not independently reproduced as article-internal defects.
