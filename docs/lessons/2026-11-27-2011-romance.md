- **romance-2026-11-27e. A new embed goes into a live post as the block Substack makes from its address.** An Instagram
  block's attributes include pictures Substack rehosts when the address is pasted (`__ss-rehost__IG-snapshot-<id>.jpg`);
  made by hand, the block would point at pictures that don't exist. So the address is pasted once into a temporary draft
  (a paste event carrying `text/plain` at the end of its body), the block Substack makes there is read

  its `videoId`.
